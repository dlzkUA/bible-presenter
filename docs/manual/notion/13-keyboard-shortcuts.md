# Keyboard shortcuts

<table header-row="true">
	<tr>
		<td>Keys</td>
		<td>Action</td>
		<td>Where</td>
	</tr>
	<tr>
		<td>→  ↓  Page Down  Space</td>
		<td>Next slide or verse</td>
		<td>Everywhere</td>
	</tr>
	<tr>
		<td>←  ↑  Page Up</td>
		<td>Previous slide or verse</td>
		<td>Everywhere</td>
	</tr>
	<tr>
		<td>F5</td>
		<td>Bring the last slide back on screen</td>
		<td>Everywhere</td>
	</tr>
	<tr>
		<td>Esc</td>
		<td>Clear the screen</td>
		<td>When no window is open</td>
	</tr>
	<tr>
		<td>B, W, period</td>
		<td>Black out the screen or bring it back</td>
		<td>Everywhere</td>
	</tr>
	<tr>
		<td>Enter</td>
		<td>Jump to a reference or search for a phrase</td>
		<td>Bible search field</td>
	</tr>
	<tr>
		<td>Ctrl+C, then Ctrl+V</td>
		<td>Duplicate a slide</td>
		<td>Song editor</td>
	</tr>
	<tr>
		<td>Enter, Esc</td>
		<td>OK or Cancel; Esc closes any open window without touching the screen</td>
		<td>Dialogs</td>
	</tr>
</table>

On a Mac, use Cmd instead of Ctrl.

<callout icon="ℹ️" color="blue_bg">
	While you type in a field, the arrows and Space behave normally and don't change slides.
</callout>
